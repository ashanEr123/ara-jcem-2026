# Data Availability Statement

Some or all data, models, or code generated or used during the study are available in a repository or online in accordance with funder data retention policies.

The public repository contains the calibration dataset and parameters, primary question register, PRM prompt and associated evaluation artifacts, and the supplementary evaluation code, anonymous numeric ratings, trial-level timing and status data, OCR edit counts, context-comparison hashes, and analysis outputs (Uduwage-Don et al. 2026). The supplementary release includes 540 completed trials and one archived failed attempt. Numeric analyses can be reproduced without API access. Private source PDFs and text-bearing supplementary records, including OCR transcriptions, retrieved passages, generated answers and evaluator comments, are excluded from the public release because access is restricted. Reassessing answer content or independently validating the OCR edit counts requires authorized access to those source materials.
