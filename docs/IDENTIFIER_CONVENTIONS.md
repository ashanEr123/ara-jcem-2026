# Identifier conventions and crosswalk

These presentation labels distinguish expert identifiers, workbook identifiers, sources and question sets. Original identifiers, filenames, numeric records and executable analysis inputs are retained for traceability. This documentation update does not change scores, timing observations or results.

| Context | Presentation label | Original identifier or scope |
|---|---|---|
| Original expert group member | PNL-01 | Original expert E1 |
| Original expert group member | PNL-08 | Original expert E8 |
| Supplementary evaluator | Evaluator 1 | PNL-01; numeric evaluator ID 1 |
| Supplementary evaluator | Evaluator 2 | PNL-08; numeric evaluator ID 2 |
| PRM workbook | PRM-01 | experiments/prm_agreement/experts/E1_completed.xlsx |
| PRM workbook | PRM-02 | experiments/prm_agreement/experts/E2_completed.xlsx |
| PRM workbook | PRM-03 | experiments/prm_agreement/experts/E3_completed.xlsx |
| Document source | SRC-C, SRC-D | Source C, Source D |
| Primary complex question | CPX-01 through CPX-10 | C1 through C10 in the primary benchmark |
| Supplementary circular question | CIR-01 through CIR-08 | C01 through C08 in the supplementary records |
| Supplementary defence question | DEF- plus existing two-digit number | D-prefixed supplementary question; e.g. D09 becomes DEF-09 |

PNL identifies an individual member of the original expert group, not a separate panel. The authors confirmed that supplementary Evaluator 1 is PNL-01 and supplementary Evaluator 2 is PNL-08. They completed their ratings independently. This does not imply recruitment of a new independent expert group.

PRM labels identify workbooks. A shared number does not establish that PRM-01 belongs to PNL-01 or supplementary Evaluator 1. No person-to-workbook correspondence is asserted without verification.

Use the full labels Evaluator 1 and Evaluator 2 in Tables 5–6. In narrative descriptions of supplementary question C03, use CIR-03 (original record ID C03). CPX-03 is a different, primary benchmark question. Source identifiers are not question identifiers.

The accompanying earlier Word supplement and archived execution instructions retain their historical labels. Apply this crosswalk when reading them; the current release documents the mapping rather than silently rewriting experimental records.

## Suggested methods wording

Supplementary ratings were completed independently by two members of the original expert group: PNL-01 (Evaluator 1) and PNL-08 (Evaluator 2). Distinct prefixes identify expert group members (PNL), PRM workbooks (PRM), document sources (SRC), and question sets (CPX, CIR and DEF). The repository crosswalk links the presentation labels to the original experimental identifiers.
