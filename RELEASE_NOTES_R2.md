# R2 supplementary release — 16 October 2026

This overlay adds the completed rerun and final independent numeric ratings to the existing research repository. The existing GitHub tree was checked before publication; its primary experiment files are preserved unchanged.

Completed archive: 540 successful formal trials, one archived failed attempt before successful retry, 108 repetition-0 rated answers, two evaluators, 200 equal-context comparisons with no mismatch. The earlier interrupted pilot is not pooled with this rerun.

Changes from the archive: private text and binary indexes removed; numeric observations exported to JSON; evaluator comments removed; final supplied Evaluator 2 counts incorporated; a standalone public analysis script added. Execution-source files listed in provenance are copied without modification. Original freeze hashes describe the private experiment, not the reduced public folder. R2_RELEASE_SHA256.json separately fingerprints the public release files.

The clean supplement is included unchanged from the revised submission package; subsequent author-confirmed clarifications are supplied in docs/R2_METHOD_CLARIFICATIONS.md. Manuscript, highlighted documents, tracked edits and reviewer correspondence are not part of this release.

No new live API experiment was performed to prepare this release. Model aliases can change. The original freeze records the execution Python version and installed packages; the archived requirements file uses version ranges. The public analysis requirements pin the NumPy version tested for this release. Fresh runs may differ and require the authorized original private inputs. The public offline analysis does not require API credentials.
